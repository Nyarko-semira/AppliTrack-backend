AppliTrack Backend

Backend API for AppliTrack, a job application tracking platform designed to help users manage job opportunities and track their applications.

This backend provides the server-side foundation for AppliTrack, including API routes, data management, authentication, and database interaction.

Project status: The backend is currently being developed separately from the React frontend. Frontend-backend integration is planned as the next phase of the project

Technologies Used
Node.js – JavaScript runtime
Express.js – Backend web framework
Prisma ORM – Database access and management
PostgreSQL – Relational database
JWT – Authentication and authorization
JavaScript / TypeScript – Backend development
REST API – Communication between client and server

Features
User Management

User registration
User login
Password handling
Authentication using JSON Web Tokens
Role-based access control

====================
Job Management

Create job listings
Retrieve available jobs
Retrieve individual job details
Update job information
Delete job listings

============================
Application Management

Submit job applications
Retrieve application information
Associate applications with users and jobs
Manage application records
Database

The application uses PostgreSQL as its relational database with Prisma ORM for database access and schema management.
